## 完成的行为

1. 在线书籍详情页新增「下载与缓存」，只列出该单本书的章节。可下载所选、继续本书队列、暂停、清理所选或本书缓存。详情页顶部的同名入口也自动使用当前书籍。
2. 书库主页入口改为已有下载书籍清单，只浏览／管理已有完整或部分缓存。查看缓存章节的子窗口也不提供下载或恢复队列。要新增下载，需前往书籍详情再打开。
3. 画质入口仅在阅读时的「阅读外观」中；沉浸模式中央点击显示浮层后也可使用。书库不再放置画质按钮。
4. 在线发现移除书源下拉框，混合搜索全部已启用来源；管理界面可勾选启用。结果保留来源并逐个显示，不等待最慢来源；旧查询不能覆盖新查询，来源失败也不丢弃其他结果。
5. 清理本书缓存不触及其他书；继续本书队列时保留其他书的待办队列；已移出书库的缓存仍可管理。

## 实测边界

多源、缓存清理和队列隔离的完整验收使用合成样本，不在实际用户书库里自动下载或清理漫画。实际公网只复核了混合搜索，没有因此宣称每个来源或全部作品正文均可用。漫画柜仍有网络错误；来源原有覆盖、认证和站点限制没有改变。

没有新增自动页面磁盘缓存。合成验收目录里的 .img 文件来自显式下载按钮，不能与在线阅读的内存缓存混淆。
