# 开发与问题反馈

当前维护目标为 Apple Silicon macOS。请先阅读 README 的构建、存储约束和已知限制。

修改时保留原书只读、无阅读页面磁盘缓存、应用包外写入、覆盖浮层不改变漫画矩形、沉浸失焦继续计时、合辑不重复计时及显式完成确认这些约束。

请使用独立 MIGI_DATA_ROOT，不提交个人书库、图书、封面或含个人路径的日志。提交前运行原生回归；平台相关问题需在 Cocoa 上验证，不能以离屏通过代替 Mac 原生通过。

问题反馈请提供版本、芯片、macOS 版本、复现步骤和预期／实际结果。图书问题优先用合成样本复现，不上传未经允许分享的图书。

项目源码许可证尚未确定；当前仅整理发布准备材料，请维护者先完成授权和第三方许可确认。
