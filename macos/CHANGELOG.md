# 变更记录

## 1.0.1 — 2026-10-12

- 声明 macOS 简体中文本地化并打包 Qt 简体中文翻译。
- 修复原生文件／文件夹选择器英文界面，补齐多文件夹选择器的中文标签和类型。
- Mac 多选提示使用 Command。

## 1.0.0 — 2026-10-12

- 从既有 Windows 功能基线完成 Mac 原生适配，保留三格式、多卷、封面、沉浸、统计和自由状态功能。
- 分离签名应用包与可写书库／缓存，加入本地 IPC 激活、中文字体、原生全屏与 Retina PDF 渲染。
- 修复像素滚动、放大拖动、关闭后的计时回调和 Cocoa 无障碍网格兼容问题。

## 源码整理 — 2026-10-15

- 整理独立 GitHub 源码目录、说明、构建／验证脚本和发布模板。
- 验收脚本去除个人图书名与私人目录，改为显式传入可选图书。
- 排除应用二进制、原书、个人书库、缓存、虚拟环境与本机临时验收资料。
