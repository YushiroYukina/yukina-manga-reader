# 右页 · MIGI

双击 start.bat 启动，或运行 dist/Migi/Migi.exe。

启动时自动在鼠标所在屏幕居中，按当前屏幕可用区域限制窗口大小，支持带缩放与非零原点的多屏排列。

主题可选择鼠尾草绿、海湾蓝、紫藤、玫瑰、琥珀和暖纸白；可在书库顶栏或阅读页「阅读外观」中切换，选择自动保存。主题只影响界面与页面周围的背景，不改变漫画原图颜色。

一级阅读页取消左侧书库栏，保留书库入口、阅读设置、计时与翻页。导入、搜索、筛选、封面和分卷管理统一放在二级书库页。点击「书库 F6」或按 F6 即可切换。书库卡片提供格式／卷数标记和已知阅读进度条；长书名自动省略，完整名称与路径可通过提示查看。

导入本地 PDF、EPUB、MOBI 或整个文件夹，也可拖入。书库仅记录绝对路径，原书移动后使用「重新定位文件」。双击书名阅读。

## 独立书库与多卷合辑

启动后默认进入独立书库。封面卡片每页 48 本，支持搜索书名／分卷／路径、合辑与独立图书筛选、最近阅读／书名／导入时间排序。双击卡片进入书籍详情，点击「继续阅读」或双击分卷打开。阅读时按 F6 或点击「书库」返回书库。

书库和分卷目录采用像素滚动。普通鼠标滚轮每格约 64 px，配合约 170 ms 的平滑过渡；触控板直接响应像素滚动，拖动滚动条可立即定位。封面重绘复用内存缩略图，减少滚动时重复读盘。

点击「＋ 批量导入」，可反复添加多个 PDF／EPUB／MOBI 文件及多个文件夹，确认列表后一次导入。文件和文件夹选择窗口均支持 Ctrl／Shift 多选，也可一次拖入多个来源进入确认列表。每个文件夹可分别合为一本多卷书，或将内部每个文件独立建书；单独选择的文件各自建书。支持包含子文件夹、移出待导入项，完成后汇总新增、更新、跳过和失败项；某项失败不影响其他来源，已有进度与状态保留。

「导入文件夹」和拖入文件夹均会让你选择：

- **合为一本书**：该文件夹作为一本多卷合辑，内部 PDF、EPUB、MOBI 作为各卷，可修改合辑名称。
- **每个文件独立建书**：适合单卷或单文件完结的漫画；也可使用「独立图书」直接多选文件导入。

可选择是否包含子文件夹。分卷初始按文件名自然排序（卷1、卷2、卷10），详情页可上移／下移调整。每卷单独保存页码，继续阅读会恢复上次打开的卷；阅读工具栏可切换上一卷／下一卷。「扫描新增卷」添加后来放入文件夹的图书，保留旧进度和缺失卷记录；文件夹移动后可「重新定位」。

已有独立书籍不会被自动删除或改成合辑。再次将其所在文件夹作为合辑导入时，会继承已有的分卷页码，原独立卡片仍保留，可自行移出书库。重复导入同一路径的同类型条目不会重复建书。

## 自由标记阅读状态

详情页「阅读状态」可选择未标记、想读、在读、已读、搁置、弃读，也可输入不超过 30 个字的自定义状态，按 Enter 或移开焦点保存。状态由你手动决定，阅读、页码变化和扫描新增卷不会自动覆盖。

阅读到最后一页时，会询问是否标为「已读」。双页模式以当前跨页包含最后一页为准；多卷合辑先确认本卷，所有分卷均为「已读」后再询问整本合辑。手动在分卷目录标记也会触发合辑确认。点击「暂不标记」或关闭弹窗保留原状态，已经「已读」的条目不再提示。当前运行期间停留在末页不会重复提示；离开末页再读到结尾可再次确认，重启后也可重新提示。合辑拒绝后，当前运行期间仅在分卷状态先变为未全部已读、再全部已读时重新询问。确认窗口等翻页动画结束再显示，沉浸模式保持。

书库卡片显示状态，顶部「全部状态」支持筛选。右键书籍卡片可以快速标记；按 Ctrl 或 Shift 多选后右键可批量标记。合辑分卷目录也有状态列，右键某卷可单独标记；整本合辑与各卷互相独立。将已有独立卷导入合辑时，会继承该卷状态，但新合辑整体仍为未标记。选择「未标记」清除状态，页码和阅读时长保留。

默认封面自动提取图书第一页，生成 420×600 的缩略图，首次显示时在独立进程中按需生成。多卷合辑默认使用第一卷；在详情页选中某卷，点击「所选卷设为封面」可指定其他卷。也可用「更换封面」选择本地图片；「重置封面」恢复第一页默认封面。源文件移动或缺失会显示提示，不修改原文件。

## 阅读计时

成功打开图书并显示阅读页后开始计时。阅读页显示本书累计时长，可点击「暂停计时／继续计时」。返回书库或统计页时暂停。普通阅读模式最小化或切出窗口时自动暂停，回到前台阅读页恢复；沉浸阅读期间不受窗口焦点、应用前后台或最小化影响，切到其他屏幕打字／查看消息仍继续计时，主动点击「暂停计时」才暂停。退出沉浸后恢复普通模式规则。使用单调时钟，系统时间调整不影响统计；电脑休眠或超过 5 秒未收到心跳的阻塞间隔不计入。

合辑按整本书累计，同时记录各卷时长；全局累计只记一次。书库顶栏显示累计阅读时长，详情页显示本书和各卷用时。每 15 秒自动保存，暂停、切书和关闭时保存；异常终止最多损失约 15 秒尚未保存的数据。移出书库不会扣除历史累计时长。旧版本未记录的阅读时间从本次更新后开始统计。

## 每日阅读统计

点击书库「累计阅读」、详情「本书累计阅读」或阅读页的时长按钮，进入独立统计页面。支持按自然周（周一至周日）、自然月与自然年查看，可切换上一期／下一期或回到今天。显示本期阅读时长、阅读书籍数、活跃天数、活跃日均、每日趋势与本期 Top 10。点击趋势图某一天，或使用日期选择器，查看当天每本书的时长；合辑可展开分卷。返回按钮或 Esc 回到原页面，查看统计时暂停阅读计时。

每日统计按本机日期记录，跨午夜时拆分到两天，不记录小时／时段分布。旧累计时长完整保留，更新前无法追溯的时间不会虚构到某一天；首次有效阅读后开始新增日记录。历史记录与书籍标题快照保存在程序目录 data/library.json，删除书库条目仍保留统计。合辑与分卷只累计一次，全局累计仍包含旧版时长。

默认右到左，双页时较早页面放右侧。封面默认单独显示。点击左半页／左方向键读下一页，右侧返回；空格下一页，Home/End 首末页，F11 全屏，Esc 退出全屏。支持单页、适合窗口、适合宽度、原始大小、缩放和跳页，滚动条可浏览放大页。

## 阅读布局与动画

- **沉浸阅读**：点击右上角「沉浸阅读」或按 Tab，全屏仅显示漫画，隐藏书库、工具栏和页码；鼠标静止 1.8 秒后隐藏指针。按 Tab、Esc 或鼠标右键退出，恢复原先窗口状态。F11 保留普通全屏功能。
- **中间点击区**：当前可见阅读区横向 35%–65%（中间 30%）不触发翻页。普通阅读点击无动作；沉浸阅读点击以浮层切换顶部阅读控件与底部翻页栏，包含已展开的阅读外观，保持沉浸全屏。浮层覆盖漫画，不占用布局空间，弹出／收起时不改变视口、漫画大小或位置。再次点击收起。控件显示时保持鼠标可见，收起后恢复自动隐藏。放大及水平滚动后仍以可见区域判断；左右各 35% 保留翻页。
- **页间距**：打开「阅读外观」，调整 0–64 px 的双页间距，默认 24 px。0 px 适合拼接跨页，间距不随图片缩放增大。单页模式不显示页间距。
- **翻页效果**：可选择书籍翻页、平移、覆盖、淡入淡出或无动画。书籍翻页含纸页透视与投影；平移让前后页面一同移动；覆盖让新页从一侧盖住旧页。方向随右到左／左到右与前后翻页反向播放，提供 260／420／650 ms 三档速度。连续翻页会立即结束上一段动画并响应新操作。
- 沉浸模式中视口尺寸变化会同步调整动画覆盖层，保留当前翻页进度；退出沉浸或切换图书时结束旧动画。
- 间距、翻页效果、速度、缩放和适配方式自动保存。动画只暂存当前视口前后两帧于内存，结束即释放，不生成磁盘缓存。

## 存储约定

不复制图书、不解压全书、不生成阅读页面磁盘缓存。封面缩略图按本次要求缓存到**可执行程序所在文件夹下的 cache/covers**，当前成品路径为 <程序目录>/cache/covers。后台进程的临时目录也固定在同一级 cache/worker-temp，不使用 C 盘缓存。程序若被移动到 C 盘，磁盘封面缓存会被禁用，不会退回 AppData 或系统临时目录。

书库显示缓存大小，鼠标悬停于缓存信息可查看实际路径。点击「清理封面缓存」可清理缩略图；当前可见书籍会按需重新生成。封面源文件修改后会生成新版本，可定期清理旧版本。仅缓存 420×600 的封面小图，阅读页面保持按需解码到内存。

软件目录下 data/library.json 保存路径、书名、页码、封面来源、阅读时长与设置（写入过程中有瞬时替换文件）。移除书库记录不删除原文件。软件运行库本身占用磁盘，与图书容量无关。

运行期间会有一个很小的 data/reader.lock 防止多个实例同时写书库，关闭后释放；重复启动会激活现有窗口。

支持无 DRM 图书，不破解加密。MOBI 由 MuPDF 支持的版本解析，复杂 Kindle/KF8 或特殊固定布局不保证兼容。文字型 EPUB/MOBI 使用固定 900×1280 排版。未提供的实际图书不能保证逐本兼容；异常会在界面提示，原文件不修改。

## 开发

Python 3.10+；安装 requirements.txt，运行 python app.py。测试：python -m unittest discover -s tests -v。

打包：python -m PyInstaller --noconfirm Migi.spec（保留 spec 中排除构建机器 Poppler ICU 的规则）。当前成品已在本机 Windows 11 验证，不承诺其他系统版本。

依赖文档：https://pymupdf.readthedocs.io/en/latest/how-to-open-a-file.html

PyMuPDF/MuPDF 使用 AGPL 或商业许可；对外分发应遵循依赖许可。PySide6 许可信息随运行库分发。
