# Mac 在线阅读操作调整 · build 20261026.4

本次修改沿用 0.1.3-preview 的书库、缓存和来源 ID，数据保持在 .app 外。

## 下载与缓存

- 在线书籍详情页（书库的二级页面）新增「下载与缓存」，打开后只列出该书章节，并区分已下载、部分下载和未下载。默认选中当前章节；可多选下载、继续本书队列、暂停、清理本书缓存和选择下载目录。
- 书库主页的「下载与缓存」只展示已有完整或部分下载的在线书籍。可以查看缓存章节、清理缓存、前往书籍详情；不提供新下载或恢复队列按钮。查看缓存章节的子窗口也不提供新下载。
- 已移出书库的下载仍可查看和清理。新写入的下载清单保存书名；旧清单在书籍仍在书库时直接使用书库标题。
- 继续某本书的队列时，只处理本书章节，保留其他书尚未完成的队列。清理本书缓存不会清理其他书或移除书库进度。

## 画质入口

书库中移除了「在线画质 / 预加载」。阅读时打开「阅读外观」即可调整，沉浸阅读时先点画面中央显示浮层，再打开同一菜单。浮层和画质对话框不改变画布尺寸或退出沉浸模式。三档画质与预读范围逻辑保持原有行为。

## 混合搜索

- 发现页面移除左侧的书源选择框，每次搜索使用全部已启用来源；在「书源管理」中通过勾选决定是否参与。
- 各来源最多四个任务并发，结果逐个返回并显示来源名称；慢源或失败来源不会挡住已返回结果。
- 相同书名／作品 ID 来自不同来源时保留为不同条目，加入书库与加载章节仍使用该条目对应的来源，避免串源。
- 返回结果按各来源交错排列；分页对全部启用来源查询相同页号，只要有来源有下一页就可继续。
- 显示已返回来源数量和失败来源信息。搜索新词或修改来源后，旧请求即使晚到也不能覆盖新结果；尚未开始的旧任务取消。已发出的网络请求可能继续到超时结束。
- 搜索使用独立线程池，不会排在读取封面的任务后面。没有改变站点的限速、认证、证书校验、内容覆盖或付费限制。

## 验证方法

`tests/test_online_workflows.py` 使用独立合成书源，覆盖多源逐步显示、失败隔离、同 ID 不同来源保留、旧请求失效、关闭来源不发请求、封面任务不阻塞搜索、单书缓存范围、已移除书籍缓存、部分下载、本书继续队列、详情下载入口、沉浸画质菜单及画布几何。

内置 `--online-validation <新目录>` 扩展为 44 项，包含真实 Qt 窗口操作、独立 HTTP 慢源和失败源、详情页发起下载、全局缓存入口检查、来源勾选和沉浸画质对话框。全部只写指定测试目录；不会载入用户的实际书库。最终打包验收结果另附日志与 JSON。

构建方式沿用原 spec，使用原生 arm64 Python；本地 ad-hoc 签名，不需要开发者账号或全局修改 Gatekeeper。未修改 Windows 或 Android 项目。
