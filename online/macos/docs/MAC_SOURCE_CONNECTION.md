# Mac 书源连接补丁 · 2026-10-26

版本仍为 0.1.3-preview，Mac 应用 build 为 20261026.2。本次针对本机网络增加每个书源独立的 connection 设置：system（默认，跟随系统代理）或 direct（此书源直接连接）。入口：书源管理 → 编辑 → 连接方式。未知值会拒绝保存。导入导出保留此字段，编辑不会丢失。未指定时保留原行为。

这台 Mac 的 Python urllib 经系统代理 127.0.0.1:7897 连接三个内置来源时出现 SSL EOF。同样的官方服务使用直接连接后，MangaDex 中文和 MangaPill 英文可搜索、读取章节清单并加载正文。该结果不代表系统代理不可用于其他程序；curl 经该代理可以连接 MangaPill。补丁没有改变系统代理、TLS 版本、证书或主机名校验，也不自动在网络失败后切换路线。

本机已把 MangaDex 中文、MangaPill 英文设为启用＋direct，漫画柜因持续超时暂时停用。没有改变用户书库、阅读进度或下载位置；原书源配置备份在本机 online-data/data/source-backups/。新源码默认书源仍跟随系统，其他用户应按自己的网络选择。

真实打包应用验收：

- MangaDex 中文：Kage no Jitsuryokusha ni Naritakute!，8 个中文／繁中章节，首章图片清单 32 页；正文显示 1080×1551，封面生成，页面磁盘文件 0。
- MangaPill 英文：搜索 Look Back 返回 4 项，选中 Look Back，1 章、142 页的图片清单；正文显示 1115×1600，封面生成，页面磁盘文件 0。请用英文作品名搜索。
- 实际验证只加载少量页面，没有下载整章；页数来自元数据，不代表逐页检查全部图片。
- 38 项在线回归通过，含新加的失效代理隔离测试、连接模式持久化和编辑器默认值／重开检查。
- 用户书库中没有加入测试作品，真实阅读在独立验证目录完成。

本次配置依赖 Mac build 20261026.2，旧应用会忽略 connection 字段。书源服务可能变化，实测时间为 2026-10-26；不能保证所有作品和之后的可用性。与原输入包的差异为 online_core.py、online_ui.py、tests/test_online.py、YukinaOnline.spec、README.md 及本文档、清单／审计元数据。未改 Android 或独立 Windows 项目。
