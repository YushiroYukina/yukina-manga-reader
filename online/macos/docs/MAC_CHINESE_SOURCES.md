# Mac 新增中文书源：动漫屋（DM5）

2026-10-26，Mac build 20261026.3。新增动漫屋中文适配器，默认书源第一项为动漫屋；原来源和旧图书的来源 ID 保留。连接方式支持本机已验证的直接连接，证书校验保持开启。

实测作品为《若叶四姐妹的青涩之恋》（35 章）、《末日虫师》（10 章）、《摇曳露营△》（125 个正文／番外条目）。三个作品均执行准确标题搜索、章节列表、第一章前两页图片下载到内存与解码；搜索约 0.35 秒，章节目录约 0.3 秒，为当时网络的单次样本，不保证固定时延。

《金牌得主》只返回《金牌得主公式漫迷手册》，没有把它当作原作；《四叶妹妹》在本次搜索没有符合标题的结果。搜索结果会保留真实标题，不用手册或同人冒充主作。动漫屋也不能保证全部漫画有可读章节；主站有下架、缺页和付费情况。锁定章节不列入公开阅读结果，不绕过登录、支付或验证码。

实现使用固定 HTML 和字面量解析，不执行网站 JavaScript：

- 搜索排除导航、分类、跨站链接和标题不匹配的近似结果。
- 保留正文／番外分组顺序，各组按网站的倒序列表恢复正序。
- 章节元数据生成惰性的逐页解析地址，不会先请求整章每页的图片解析接口。
- 只有用户翻到或预读到相应页时，才解析该页地址；图片请求携带对应章节 Referer。
- 阅读图片沿用有容量限制的 RAM 缓存，不新增磁盘页面缓存。封面仍使用独立小图目录。
- 主动下载沿用独立缓存、SHA-256 校验和暂停续传。页的标识不随临时签名变化，避免签名更新后重复下载已校验的页面。

新增适配器测试含真实标题与手册区别、章节分组与锁定过滤、逐页延迟请求、固定字面量解析、非法解析地址拒绝、缺少公开令牌拒绝、Referer、临时签名下的断点复用。原在线功能回归仍须通过。

协议参考：Keiyoushi contributors 的 DM5 扩展（Apache-2.0）：
https://github.com/keiyoushi/extensions-source/tree/main/src/zh/dm5

本项目自行实现 Python 固定解析器，没有打包或运行上游扩展 APK、远程脚本。新构建只作用于本 Mac 在线版，不改 Windows 或 Android 项目。
