# Windows 在线版 0.1.4 更新

基于 0.1.3-preview，新增三项内置书源、启用来源混合搜索、按书籍管理下载及阅读内画质菜单。全局下载页面只管理已有下载，可通过「进入书籍详情」继续操作。

Windows 使用独立书库，不迁移本地版书库；已有在线版升级保留 online-data 和独立下载目录。Android、Mac 本次没有同步开发或设备验证，不应将此包作为跨平台更新。

新增来源已完成真实公开作品搜索、章节、图片解码检查，记录见 WINDOWS_SOURCES_VALIDATION.json。ComicABC 只显示公开作品；MangaKatana 部分源站首图留白，保持原页序。实际可用性受网络和站点变更影响。

合成测试不包含实际漫画页面。最终成品检查记录见 WINDOWS_UPDATE_VALIDATION.json。原有跨平台验证文件为历史记录，不代表本次复测。

本次在线回归 35 项、新流程测试 5 项通过；Windows 成品新流程 23 项、在线回归 27 项通过。两项新增中文来源在成品内成功生成封面并渲染正文，未产生页面磁盘缓存。完整旧桌面测试在无人值守窗口切换时未完成，因此不宣称整套旧测试通过。
