# 独立在线版 0.1.1-preview：常用书源预设

本次只更新独立在线版；原本地版与原书库继续保留。

- 默认内置漫画柜（中文）、MangaDex（中文）与 MangaPill（英文），直接在「在线发现」选择，无需自建服务器。
- 首次升级补齐缺少的预设，保留已有名称、认证、启用状态、书库、阅读记录与下载路径。之后手动移除的书源不会随每次启动重新加入；可导入附带的 `sources/common-presets.json` 恢复。
- MangaDex 搜索按章节语言筛选，减少打开作品后没有中文章节的情况。
- 新增固定 HTML 与图片清单解析、来源标识、公开图片签名刷新及有限网络重试；不运行远程脚本，不绕过登录或验证码。

三个默认书源已在开发电脑验证搜索、章节和单页图像解码。Windows 成品完成 27 项界面流程检查。共享桌面回归 56 项、在线检查 29 项、Android 主机规则 39 项与生产 Java 协议检查 39 项通过。

Android 独立包 `cn.yukina.online`，versionCode 2，可使用相同签名升级前一在线预览版。Mac 提供更新后的 Apple Silicon 源码与构建脚本；本次没有进行平板或 Mac 实机验证。

仅主动下载才会将漫画页写入已选择的独立缓存目录。书源内容、地区网络与网站接口可能变化；可用性记录见 `COMMON_SOURCES_VALIDATION.json`，平台验证范围见 `BUILD_VALIDATION.json`。
