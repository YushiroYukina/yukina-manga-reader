# Android 在线版 0.1.4 更新与真机验证

本次把 Windows 已完成的混合搜索、三项新增书源、按书籍管理下载、全局已有缓存浏览和阅读内画质菜单适配到 Android 独立在线版。增加了缓存刷新、下载准备提示、来源错误说明和书库来源名称；在线目录使用章节称谓。

- 构建及基础规则：39 项通过。
- 生产 Java 协议及队列／解析规则：63 项通过。
- 最终安装成品：15 项真机核对通过，APK 哈希与平板已安装文件相同。
- TF 卡目录由系统文件夹选择器正常授权，未使用额外目录授权辅助程序。
- 《One Piece》第 2 章 24 页下载至 TF 卡，全部 SHA-256 匹配，关闭 Wi-Fi 后仍可离线打开。
- MangaPill、包子漫畫.org、MangaKatana 已打开实际章节；ComicABC 在当前网络返回 403、漫画柜连接超时，不计为通过。

本轮设备为联想 TB371FC，当前系统实际为 Android 15 / Lineage GSI，与之前 Android 14 ZUI 不同。本次结果不能直接当作原 ZUI 的复测结果。详细证据与未覆盖项目见 ANDROID_UPDATE_VALIDATION.json。

安装使用独立包名 cn.yukina.online，与本地版 cn.migi.reader 并存。本地阅读器、Windows 产品代码和 Mac 产品代码均未修改。多次同签名覆盖安装后，在线书库、进度、来源设置和 TF 卡下载目录保持可用。

平板保留三本实测作品的在线书库记录和一章 TF 卡下载供体验。临时修改的来源启用状态、输入法和 USB 保持亮屏选项均已恢复；Wi-Fi 已重新联网。

尚未在真机单独执行跨书籍并发队列的暂停／继续或删除实书缓存，这些不得视为全部设备场景已经通过。下载队列隔离有生产 Java 主机检查。用户可在书源管理停用当前不可访问的来源。
