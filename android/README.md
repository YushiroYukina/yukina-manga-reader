## 已实现的基础功能

批量合辑：书库“＋ 批量合辑”选择 Manga 等父目录，扫描直接子文件夹，每个作品文件夹作为一本多卷书。扫描后可多选、全选或全不选。只读取各作品内部的 PDF／EPUB／MOBI，父目录直属散装文件不纳入此模式。最多 5000 卷。TF 卡入口也可选批量合辑，目录授权位置不同仍按原文档标识去重。

- 系统文件选择器多选 PDF／EPUB／MOBI 文件，持久保存只读 URI 授权。文件夹支持包含子目录、合为多卷合辑或逐文件独立建书，自然卷号排序，重复导入去重。增加独立“TF 卡”入口，通过 StorageManager 枚举外置存储并显示挂载状态；可批量选文件或选文件夹，系统选择器初始定位到所选卡。只读卡也可导入。
- 独立书库网格、搜索、详情、分卷目录、阅读进度恢复、跳页及手动阅读状态，包括自定义状态。支持单卷、整个合辑或合辑内某一卷移出；支持清空书库。最后一卷移出时去掉空合辑，自动调整当前卷和封面卷。所有移除只修改书库记录，不改动原文件，保留历史统计和设置。
- 打开图书直接沉浸；横屏双页，竖屏单页，封面单独显示，旋转保持页码。默认右到左，可切换方向。
- 中间 30% 点击仅切换上下覆盖浮层，浮层不参与阅读画布布局，不挤压漫画；两侧翻页。支持双指缩放、放大后拖动、双击缩放。原比例下从中央 30% 区域外起拖，拖动时动画实时跟随手指，松手时越过屏幕 50% 中线进入另一半则完成翻页，否则回弹；每次触摸最多一次，从中央开始不翻页，短滑回弹。相邻页只在内存异步解码，完成动画后更新阅读进度；无动画模式拖动使用位移反馈。
- 与 Windows 相同的固定书脊单叶投影、纸边抬起和阴影书籍效果、平移、覆盖、淡入淡出和无动画；0–64 dp 页间距；六套主题。
- 默认封面提取第一页为 420×600 PNG 小图；合辑可选择任意分卷或授权本地图片作总封面。封面缓存可清理；返回书库时自动重试缺失封面。
- 阅读时长按单调时钟累计；分屏中阅读界面仍可见时不因失焦暂停，主动暂停、完全后台、锁屏或离开阅读页时暂停。延迟超过 5 秒的心跳不计入，避免休眠时间混入。每 15 秒及切页／退出时保存。
- 自然周／月／年每日趋势、Top 10、日期选择和当天各书／分卷时长。跨午夜拆分，合辑只累计一次，不做小时分布。读到最后一页确认“已读”，全部分卷已读后另行确认合辑。

## 格式范围

| 格式 | 当前实现 | 范围与限制 |
|---|---|---|
| PDF | 安卓系统 PdfRenderer | 无密码、可寻址的本地文件描述符；不复制文件以绕过不可寻址来源 |
| EPUB | ZIP 中央目录定位 + OPF spine 顺序 | 图片漫画，包括标准 DOCTYPE 的 XHTML img／SVG image 引用（不加载外部 DTD）；暂不排版文字型 EPUB，暂不支持 ZIP64、DRM |
| MOBI | Palm 数据库记录与 recindex 图片引用 | MOBI6 无压缩／PalmDOC 压缩图片漫画；暂不支持文字排版、HuffDic、KF8／AZW3、DRM |

三种格式已在 TB371FC／Android 14／arm64 上用生成样本实际解码，页数、首／后续页像素和源文件哈希检查通过。样本通过不代表每本真实图书都兼容。单张图片条目限制 32 MiB；渲染图片限制解码尺寸，只保留当前／翻页所需页面于内存。

## 存储约定

不复制图书、不解压整本、不缓存阅读页面。书库只保存系统授权 URI。元数据为应用私有 `files/data/library.json`，采用 AtomicFile；封面小图为应用专用外部目录 `covers`，外部目录不可用才使用应用私有 `files/covers`。自选封面只保存原 URI。没有联网权限，也不请求“所有文件访问”权限。

首次使用从系统选择器授权具体图书目录即可；安卓 14 可能限制授权整个存储根目录，因此建议选内部存储或 TF 卡内的 `Manga` 子文件夹。卸载会删除应用元数据和应用专用封面，并释放 URI 授权；原图书由用户目录持有，不由应用删除。

## 本机构建

项目使用 Java + Android 原生 View，不依赖第三方阅读 SDK，不需要 Gradle 下载整套依赖。

```powershell
python tools/bootstrap.py
python tools/build.py
# 构建独立安卓验收 APK：
python tools/build.py --instrumentation
```

Python 只使用标准库。JDK、SDK、开发签名、构建输出均位于项目 D 盘目录。构建脚本使用官方 AAPT2、D8、zipalign、apksigner，设置独立临时目录，处理中文路径并运行主机端规则测试。打包本身不会连接设备。

`tests/assets` 是独立生成的纯色 PDF／EPUB／MOBI 测试样本，不是用户图书；只打进测试 APK，不打进普通阅读器 APK。先使用 `python tools/build.py --instrumentation --qa` 构建独立验收应用，再运行 `python tools/device_verify.py --serial 明确设备序列号 --physical`。脚本只清空独立 QA 包；不清空或写入正式 cn.migi.reader 书库。原文件哈希、格式解码、横竖屏、浮层像素、计时、目录授权和持久化等 24 项已通过真机检查。真实 TF 卡及系统文件选择器的手动操作仍待验证。
